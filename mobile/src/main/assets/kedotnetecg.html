🫀 HeartRate Monitor — Researcher Guide

1. System Overview

This app collects physiological data from two sensor nodes for stress detection research:

  • Node A — Polar H10: ECG data via BLE (sampling rate: 130 Hz)
  • Node B — Galaxy Watch 5: PPG data via Samsung Health SDK (Green, IR, Red channels at 25 Hz)

Data is saved as CSV files for offline analysis in Python/MATLAB.

2. Device Setup

Polar H10 Chest Strap

  • Moisten electrode pads with water or electrode gel
  • Position strap just below the chest muscles
  • Ensure snug fit — too loose causes motion artifacts
  • Set the Device ID in Menu → Set Device ID (format: A1B2C3D4)
  • The LED should blink once paired

Galaxy Watch 5 (PPG)

  • Wear the watch 2 cm above the wrist bone
  • Tighten strap so there is no gap with the skin
  • Avoid placing over tattoos or thick body hair
  • Launch the wear app before starting recording on the phone
  • Uses Samsung Health SDK priv-health-tracking-v.1.2.0.aar

3. Recording Protocol

  1. Set the Polar Device ID in Settings → Device ID
  2. Set the data directory via Menu → Set Data Directory
  3. Wait for "Connected" status on the ECG sensor card
  4. Confirm PPG cards show "Connected" or "Streaming"
  5. Press the Record button (red pulsating FAB)
  6. Use the Flag button to mark events (Stress, Rest, Task Start, Task End)
  7. Press Pause during breaks if needed
  8. Press Stop → Save All Data when finished

5. Troubleshooting

ECG shows flat line

  • Check if the Polar strap electrode pads are moist
  • Ensure skin contact is firm and continuous
  • Try Menu → Restart Polar API
  • If still flat, re-wear the strap with fresh moisture

PPG data missing or not streaming

  • Verify the watch app is open and running
  • Tap the PPG sensor card on the dashboard to toggle the tracker
  • Check that PPG cards show "Streaming"
  • Restart the watch app if status shows "Disconnected"
  • Ensure watch strap is tight against the skin

App unresponsive / freezing

  • Wait 5 seconds — the app may be processing a large batch of data
  • If frozen, press Stop to save current data
  • Use Menu → Redo Plot Setup to reset graphs

Recording stops unexpectedly

  • Ensure battery saver is OFF on the phone
  • Disable battery optimization for this app in Android Settings
  • Keep the phone plugged in for long recording sessions (> 1 hour)

6. Best Practices for Data Quality

  • Do a 2-minute baseline recording at rest before each session
  • Mark events immediately using the Flag button
  • Keep subjects seated and still to minimize motion artifacts
  • Verify data after each session by checking the CSV file row counts
  • Back up data after each recording session
